# Задание 2. Погода в городах и статистика по странам

Решение на Python выполняет все пять пунктов задания. Используется только
стандартная библиотека. Сторонние пакеты и ключи API не нужны.

## Требования и запуск

Нужны Python версии 3.10 или новее и доступ к `https://wttr.in`.
Запуск из папки задания:

```sh
python3 main.py
```

В Windows можно использовать `py -3 main.py`, если команда `python3` недоступна.

По умолчанию программа читает `cities.txt` рядом со скриптом. Это работает
и при запуске из другой папки. Другой файл можно передать первым аргументом:

```sh
python3 main.py /путь/к/городам.txt
```

Входной файл должен быть в кодировке UTF-8, по одному городу на строку.
По умолчанию время ожидания сетевой операции составляет 15 секунд.

## Состав решения

- `cities.txt`: восемь городов из условия задания.
- `main.py`: чтение файла, запросы к API, модель данных и вывод результатов.
- `test_main.py`: автоматические тесты с подготовленными ответами API.
- `README.md`: описание решения и инструкции по запуску.

## Алгоритм

1. Прочитать список городов из файла в память. Удалить пробелы по краям строк,
   пропустить пустые строки и необязательную метку BOM. Удалить повторы без
   учёта регистра, сохранив порядок и первое написание каждого города.
   Разные варианты названия одного города автоматически не объединяются.
2. Для каждого уникального города последовательно выполнить один запрос
   к `https://wttr.in/{City}?format=j1`. Название кодируется для URL функцией
   `urllib.parse.quote`. Запрос выполняется через `urllib.request`,
   ответ разбирается стандартным модулем `json`.
3. Создать экземпляр неизменяемой модели `WeatherData` с полями `city`,
   `temperature_c` и `country`. Название города берётся из входного файла,
   текущая температура из `current_condition[0].temp_C`,
   страна из `nearest_area[0].country[0].value`.
4. Вывести город, страну и текущую температуру в градусах Цельсия.
   Порядок городов соответствует входному файлу.
5. Сгруппировать результаты по странам и вывести страны в алфавитном порядке.
   Для каждой группы вычислить количество городов, среднюю, минимальную
   и максимальную текущую температуру. Средняя температура рассчитывается
   как сумма температур, делённая на количество городов в группе.

Страны и температуры не заданы в коде заранее. Местоположение определяет
сервис wttr.in. Для неоднозначного названия можно уточнить страну во входном
файле, например `Vienna, Austria`.

Округление выполняется только при выводе: не более одного знака после запятой.
Для температуры явно указываются знак и единица измерения `°C`.

Описание формата ответа доступно в
[документации wttr.in](https://github.com/chubin/wttr.in#json-output).

## Обработка ошибок

Если файл отсутствует, недоступен, пуст или имеет неверную кодировку,
программа выводит понятное сообщение в стандартный поток ошибок.
Аналогично обрабатываются ошибки HTTP, проблемы соединения, превышение
времени ожидания, некорректный JSON и отсутствие нужных полей в ответе.

Ошибка запроса для одного города не мешает обработке остальных. Неполный
отчёт помечается `PARTIAL REPORT`, а статистика рассчитывается только по
городам, для которых удалось получить данные. Если не выполнен ни один
запрос, статистика не выводится. Тестовые значения не подставляются.

Автоматических повторных запросов нет. Ограничение времени относится
к отдельным сетевым операциям, а не ко всему запуску программы.
При временной недоступности API программу можно запустить позже.

Коды завершения:

- `0`: данные получены для всех городов, отчёт полный.
- `1`: ошибка файла, запроса или данных, в том числе неполный отчёт.
- `2`: некорректные аргументы командной строки.
- `130`: выполнение прервано сочетанием Ctrl+C.

## Тесты

Запуск из папки задания:

```sh
python3 -B -m unittest -v
```

Тесты работают без интернета. Проверяются удаление повторов, обработка BOM
и пустых строк, выбор текущей температуры, проверка ответа API, кодирование
URL, сетевые ошибки, расчёт статистики, отрицательные и нулевые температуры,
группы из одного города, частичный и полный отказ запросов, ошибки входного
файла и проверка ограничения времени ожидания.

## Результаты проверки

Проверено 11 октября 2026 года на macOS с Python 3.12.2:

- Все 12 автоматических тестов прошли успешно.
- Запуск с настоящим API получил данные для всех восьми городов,
  вывел результаты и завершился с кодом `0`.
- Получено три группы: Австрия, 2 города; Россия, 5 городов; Вьетнам, 1 город.

В локальной установке Python отсутствовал стандартный набор корневых
сертификатов, из-за чего возникала ошибка `CERTIFICATE_VERIFY_FAILED`.
Проверка с настоящим API прошла при использовании существующего набора
сертификатов macOS. Проверка сертификатов HTTPS оставалась включённой.

На этом Mac при такой ошибке можно запустить программу следующим образом:

```sh
SSL_CERT_FILE=/etc/ssl/cert.pem python3 -B main.py
```

Переменная окружения действует только для этой команды и не меняет системные
настройки. При корректно настроенных сертификатах Python достаточно обычной
команды `python3 main.py`.
